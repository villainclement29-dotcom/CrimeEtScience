# Clue Hunting - Crime & Science

Jeu d'investigation en local a deux joueurs sur trois ecrans. Incarnez des agents de la police scientifique et resolvez une affaire criminelle en collectant des indices et en analysant des preuves.

## Installation

### Prerequis

- Windows 10 ou superieur
- 3 ecrans connectes (recommande pour l'experience complete)
- 2 manettes (Xbox, PlayStation ou compatibles)

### Etapes

1. Rendez-vous sur la page du depot GitHub du projet.
2. Telechargez l'archive **ClueHunting.rar** disponible a la racine du depot.
3. Extrayez le contenu de l'archive a l'emplacement de votre choix.
4. Dans le dossier extrait, double-cliquez sur **CrimeEtScienceGame.exe** pour lancer le jeu.

### Configuration des ecrans

Le jeu utilise trois ecrans :

- **Ecran 1** : Vue du Joueur 1
- **Ecran 2** : Vue du Joueur 2
- **Ecran 3** : Leaderboard et scores en temps reel

Si vous ne disposez que d'un ou deux ecrans, le jeu reste jouable mais certains affichages ne seront pas visibles.

## Comment jouer

1. Connectez deux manettes avant de lancer le jeu.
2. Au menu principal, chaque joueur entre son pseudo a l'aide du clavier virtuel.
3. Suivez les instructions du Chef de la Police lors des tutoriels.
4. Explorez la scene de crime, photographiez les indices et analysez les preuves avant la fin du temps imparti.
5. Le joueur avec le meilleur score remporte la partie.
